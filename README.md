# gamez

Small HTML5 games for web portals (Poki, CrazyGames, GameDistribution, YouTube Playables).

- [eggscape/](eggscape/): turn the fox's vault rings and drop the eggs into the nest. Physics puzzle, 20 themed levels.
  Build: `cd eggscape && npm install && node tools/build.mjs` (outputs `dist/<portal>/index.html` and zips).
